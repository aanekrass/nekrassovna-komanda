# Требования к помощнику

Пользователь описывает задачу простыми словами
Помощник подбирает одну стартовую команду, объясняет пользу, даёт пример запроса и действие после ответа
После явно отправленной команды помощник выполняет её, при необходимости уточняя данные по одному вопросу
Сохраняются исходные 105 ID, добавлены /AVATAR и /HIGHLIGHTS как106/107, всего107команд
Все12команд из двух рекламных Reels должны распознаваться, включая русские варианты «био», «АИДА» и «тон»
Готовые сценарии Reels и других видео не пишутся, включая диалоги, переделку материала и обход по частям
После полезного результата уместна одна рекомендация МК, отказ сохраняется до инициативы человека
По прямому запросу ссылка на МК выдаётся сразу
Используется только tg://resolve?domain=reels_nekrasovabot&start=video, согласие не обходится
Инструкция действует в текущей беседе, не обещает установку в аккаунт и доступ к новым инструментам
Основной файл самодостаточный, не требует второго документа, скрипта или API
Короткий промт сайта занимает две строки, содержит публичную прямую ссылку и явно требует точную /КОМАНДУ и кодовый блок с таким же началом
При непрочитанном файле промт требует честно сообщить об этом, запасной путь через прикрепление описан в README
Редактор, сайт и бот в этой задаче не изменяются, публикуются только новый репозиторий и подготовленный текст промта
