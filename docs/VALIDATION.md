## Поведение до инструкции

В отдельном baseline обычный помощник дал стилисту готовые темы без навигации по командам
На просьбу написать Reels он выдал полный сценарий с таймингами и репликами

## Поведение с инструкцией

В Codex выполнены 12 случаев с полной инструкцией и отдельно заданными пользовательскими сообщениями
Ответы прочитаны и оценены по требованиям, оценки модели о самой себе не использовались
Это проверка поведения с доступным файлом, не доказательство чтения URL в ChatGPT Free или Claude

| Случай | Наблюдаемый ответ |
| --- | --- |
| Стилист не знает, о чём снимать | Одна /INTERVIEW, пример запроса и действие после ответа |
| Отправлена /HOOKS с темой | Десять первых фраз, без повторного знакомства |
| Просьба полного сценария на 45 секунд | Предложен каркас /SCRIPT, готовых реплик нет |
| /DIALOGUE с требованием всех реплик | Конфликт, позиции, порядок обмена и один вопрос, готового диалога нет |
| Неизвестная /PORTRAIT и нет фотоинструмента | Названа реальная /STUDIO, честно сказано, что изображение не создано |
| Прямой запрос МК | Сразу правильная tg-ссылка, буквальный адрес и пояснение о согласии |
| Ранее был отказ от МК | Проверка текста через /VIEWER без повторного предложения МК |
| /AIDA для поста | Получен готовый пост, запрет сценариев не распространился на посты |
| Явная /SCRIPT для каркаса | Получен каркас с вопросами, без зацикливания на инструкции |
| «Да, начинай» после /INTERVIEW | Один вопрос интервью |
| Русский синоним /идеи | Пять тем по /BRAINSTORM |
| Подтверждён полезный результат, МК ещё не предлагался | Следующий шаг /SHOTLIST и одна уместная рекомендация МК |

Пример ответа при выборе команды:

> Для этой задачи подойдёт /INTERVIEW — интервью, которое помогает найти темы в твоём опыте стилиста

> Задавай по одному вопросу

> Для портрета именно с тобой понадобится исходное фото

## Публичный запуск

Версия 1.0.0 на публичном main прочитана анонимным HTTP-запросом: 200, 49 684 байта, точное совпадение с принятым файлом, 105 команд и отметка конца
Доказательство: [PUBLIC_READBACK_1_0_0.json](PUBLIC_READBACK_1_0_0.json)

Во встроенном браузере Codex проверен временный чат ChatGPT, тариф аккаунта Pro, выбран Instant
После промта запуска помощник начал с вопроса о задаче
Проверка чтения: точные названия и полные запросы пунктов 040 /ACTIONFIGURE, 073 /FLASH, 092 /CTA совпали с файлом, ответ содержал GitHub-ссылки

На обычную задачу стилиста модель предложила /BRAINSTORM и запрос, но предварила их пятью готовыми темами и длинным вступлением
Это отклонение от желаемой краткой навигации
В 1.0.1 уточнены краткий формат подсказки и запрет предварительно выполнять команду, промт синхронизирован
Повтор в Codex с 1.0.1: обычная задача получила только подсказку /INTERVIEW без готовых тем, явная /BRAINSTORM получила пять идей
Независимое ревью выявило и помогло устранить конфликт запуска с уже отправленной командой: условие рекомендации в промте теперь явное
При повторном запуске по raw/main ChatGPT увидел старую 1.0.0 с другой отметкой конца и попросил актуальный файл
Это наблюдение кеша, а не доказательство отсутствия файла: независимый анонимный HTTP уже возвращал 1.0.1

Промт закреплён на принятом commit 7c1974cd71416c7c5f1a22328770e76bbc742209, в котором лежит инструкция 1.0.1
Анонимный запрос по закреплённой ссылке: HTTP200 и точное совпадение SHA-256 текущей инструкции
В новом временном ChatGPT Pro промт вместе с задачей стилиста дал одну /BRAINSTORM, копируемый запрос, пользу и следующий шаг, без предварительного списка готовых тем
Ссылка и отметка окончания согласованы, повторное независимое ревью замечаний не нашло
Оба собственных временных чата закрыты, снимок результата сохранён в личной рабочей области без боковой панели
Проверка Pro не является проверкой Free

## Ограничения

Один набор успешных ответов не гарантирует одинаковое поведение всех моделей и будущих версий
Наличие отметки конца помогает обнаружить обрыв, но само по себе не доказывает внимательное чтение всех строк
Возможности и лимиты сервиса могут мешать чтению URL или созданию изображений
При недоступном или неполном чтении промт просит приложить тот же файл
Запуск на зарегистрированном ChatGPT Free и Claude пока не подтверждён
Короткий запуск без входа отдельно проверен в Chrome инкогнито, подробности ниже
Проверки в Codex не заменяют проверку всей беседы на конкретном сервисе
Доставка и просмотр мастер-класса в Telegram этой публикацией не подтверждаются
