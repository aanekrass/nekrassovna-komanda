# Короткий запуск с явными командами

Промт сайта: две строки, 399 символов с завершающим переводом строки
Каталог остаётся в одном файле по закреплённой ссылке
Сам файл помощника 1.0.1 и все105команд не менялись

## Проблема

Пользователь проверил прежний промт в Chrome инкогнито без входа
На «нет идей для рилс» помощник дал обычный текст запроса и не назвал /BRAINSTORM
Прежний запуск просил «предложить команду», но прямо не требовал её точного имени со слешем и повторения в блоке запроса
Проверка на Pro эту ошибку в гостевом режиме не выявила

## Изменение

Короткий промт прямо требует точную /КОМАНДУ из каталога, копируемый блок с тем же началом и выполнение после отправки команды
Обычные советы не заменяют команду
Непрочитанный файл нельзя выдавать за прочитанный
Полный каталог в промт не вставляется, неопубликованный длинный вариант удалён

## Фактическая проверка

Две новые беседы открыты в своём окне Chrome инкогнито
В обеих видны кнопки входа и регистрации, вход в аккаунт не выполнялся

| Проверка | Наблюдение |
| --- | --- |
| Новый чат A, затем «нет идей для рилс» | Названа /BRAINSTORM, запрос начинается с /BRAINSTORM и находится в копируемом блоке |
| A: отправлена /BRAINSTORM с нишей и количеством5 | Получены пять идей, команда выполнена без повторения инструкции |
| A: пункты040,073,092 | /ACTIONFIGURE, /FLASH, /CTA и полные шаблоны точно совпали с файлом |
| Новый чат B, тот же короткий запуск | Подтверждение и вопрос о задаче |
| B: задача про первые фразы | Запрос остановлен гостевым лимитом, результат команды не получен |

Пример реально полученного начала ответа:

> Для этого подойдёт /BRAINSTORM — генерация разных идей контента

Копируемый блок ответа начинался так:

```text
/BRAINSTORM — Предложи 15 разных идей контента для [моя ниша, моя аудитория]
```

Это выдержки ответа, не подмена всего ответа отредактированным примером
Публичная квитанция проверок: [SHORT_LAUNCH_PROOF.json](SHORT_LAUNCH_PROOF.json)
Личные ссылки на гостевые чаты и переписка пользователя не публикуются

## Границы результата

Пройден полный путь выбора и выполнения одной команды без входа, чтение трёх точных пунктов каталога и повторный запуск
Второй запрос после повторного запуска не считается пройденным: сработал общий гостевой лимит
Проверка без входа не обозначается как проверка зарегистрированного аккаунта Free
Claude и естественная доставка МК не проверены
Одинаковые ответы всех будущих моделей не гарантируются
Свои тестовые вкладки закрыты, исходная вкладка пользователя сохранена, неиспользуемое JS-ядро сброшено
