# Создание и публикация помощника по командам

> Исполнение: в текущей сессии по executing-plans, с независимой итоговой проверкой

**Цель:** опубликовать самостоятельный файл со105 командами и подготовить промт для сайта
**Архитектура:** один Markdown-файл, читаемый из открытого GitHub без авторизации, с полным каталогом и правилами диалога
**Стек:** Markdown и TXT, без приложения, сервера, ключей и оплачиваемого API
**Основание:** [SPEC.md](../../SPEC.md)

## Общие ограничения

- Обучать использованию команд и выполнять их после явного запроса
- Не писать готовые сценарии видео и не собирать их по частям
- Сохранить105 ID, доступные текстовые задачи и корректную обработку недоступных инструментов
- Ссылка МК: tg://resolve?domain=reels_nekrasovabot&start=video
- При недоступном или неполном чтении файла просить прикрепить его, не имитировать загрузку
- Не менять сайт, редактор, бот и их данные
- Публиковать только безопасный разрешённый набор файлов

## Особое внимание при проверке

1. Обычная задача должна приводить к подсказке команды, а отправленная команда — к выполнению
2. Просьба написать сценарий и обход через другую команду должны сохранять авторство человека
3. Отказ от МК не должен превращаться в повторяющуюся рекламу
4. Недоступный инструмент фото и отсутствующие данные не должны давать выдуманный результат
5. Частично прочитанный файл не должен изображать успешный запуск
