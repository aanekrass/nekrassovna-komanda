## Доставка проверенной версии

ChatGPT может получать старую копию raw/main после обновления файла
Промт запуска должен использовать raw-ссылку на точный принятый commit с нужной версией инструкции
Перед сменой ссылки проверять анонимное чтение, SHA и совпадение отметки окончания
Не считать заявление модели о полном чтении доказательством, проверять несколько точных пунктов каталога
