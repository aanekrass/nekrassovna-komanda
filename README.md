# nekrassovna-komanda

Помощник по 107 командам для блога

Помощник Виктории Некрасовой объясняет, какую команду выбрать, как написать запрос и что делать с ответом
Человек осваивает команды на собственной задаче
Готовые сценарии Reels и других видео помощник не пишет

## Начать

Промт запуска занимает две строки и требует показывать точные команды вроде /BRAINSTORM
Каталог из107команд остаётся по ссылке, вставлять весь каталог в чат не нужно

1. Открой [промт запуска](site-prompt.txt) и скопируй его целиком
2. Вставь в обычный чат ChatGPT или Claude
3. Посмотри меню16разделов, открой интересный раздел или напиши «Покажи все команды», чтобы прочитать все107прямо в чате
4. Выбери команду или опиши задачу и пройди предложенный шаг

Приложение и программирование не нужны
Инструкция действует в текущей беседе, она не устанавливает постоянный навык в аккаунт

## Если ссылка не прочиталась

Открой [сам файл](blog-assistant.md), выбери Raw и сохрани его
Прикрепи файл к чату и напиши:

> Используй приложенный файл как руководство по командам для блога в этой беседе и начни с меню всех16разделов и возможности показать полный список в чате

Если загрузка файлов недоступна, скопируй содержимое файла и вставь в чат
Доступ к сайтам, загрузка файлов и инструменты создания изображений зависят от сервиса и его текущих лимитов

## Что внутри

- Все107 команд в одном [файле помощника](blog-assistant.md)
- Первое меню16разделов и полный список команд по запросу внутри чата
- Выбор команды по описанию задачи и готовые примеры запросов
- Уточняющие вопросы по одному и объяснение, что делать с результатом
- Идеи, хуки, смысловые каркасы, планы кадров, разборы и другие задачи блога
- Разные действия при рекомендации команды и после её отправки
- Поддержка понятных русских вариантов вроде /идеи, /хуки и /шапка
- Рекомендация мастер-класса после пользы, без повторов после отказа

Помощник может помогать с запросами для изображений, но файл не добавляет отсутствующий инструмент генерации

## Мастер-класс

Прямой адрес для открытия Telegram и входа на мастер-класс:

```text
tg://resolve?domain=reels_nekrasovabot&start=video
```

Для нового пользователя перед мастер-классом сохраняется согласие
